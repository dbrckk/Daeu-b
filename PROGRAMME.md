# Référentiel de mathématiques du DAEU B — version 2026-2027

## Statut et limites
Il n'existe pas un sujet ni un programme unique pour toutes les universités françaises : le tronc commun est proche, mais certaines demandent aussi trigonométrie, géométrie, calcul intégral, voire nombres complexes. **Toujours comparer avec le programme et les annales de l'université dans laquelle on passe l'examen.** Le référentiel principal de ce dépôt est la préparation **DAEU B à distance via SONATE** (100 h équivalent présentiel), mise en regard des programmes UGA, Rennes et Paris-Saclay. Les documents ici sont des cours **originaux de préparation**, pas des supports officiels.

Sur certaines universités le calendrier, les coefficients, le contrôle continu et l'épreuve finale changent. SONATE annonce une épreuve finale de mathématiques **3 h, trois exercices indépendants** (vérifier les consignes de sa session).

## Couverture supplémentaire pour éviter les lacunes selon l'université
- **13 Trigonométrie** : Rennes, UGA et Sorbonne.
- **14 Vecteurs / équations de droites / produit scalaire** : Rennes, UGA.
- **15 Primitives / intégrales / équations différentielles** : Rennes, UGA, Paris-Saclay. L'intégration par parties est explicitement demandée à Paris-Saclay (2025-2026).
- **16 Nombres complexes** : Orléans, Sorbonne ; **pas** annoncés dans le synopsis SONATE actuel, donc facultatifs tant que l'université ne les exige pas.
- **17 Logique, preuves, problèmes** : transversal.
- **11 Statistiques plus approfondies** : variance, écart-type, quantiles ; intervalle de confiance selon Paris-Saclay.

## Compétences cibles, par domaine
1. Calcul : résultat exact puis éventuellement approximation, unités, priorités, simplification de fractions, puissances, racines.
2. Algèbre : identifier le domaine, développer/factoriser, résoudre et vérifier équations/inéquations/systèmes, utiliser un tableau de signes.
3. Analyse : déterminer le domaine, la dérivée, les variations, les limites/asymptotes, dresser un tableau de variations, justifier l'existence et l'unicité d'une solution ; interpréter et tracer.
4. Exponentielle/logarithme : utiliser les propriétés **avec leurs conditions d'existence** et résoudre des problèmes.
5. Suites : reconnaître arithmétique/géométrique, calculer une formule explicite, une somme, un comportement limite.
6. Probabilités/statistiques : construire un arbre, distinguer conditionnel et indépendance, calculer l'espérance et une probabilité binomiale, interpréter une distribution.
7. Compléments : trigonométrie, géométrie vectorielle, primitives/intégrales selon l'établissement.
8. Communication : rédiger proprement les étapes, vérifier la plausibilité et conclure dans le contexte.
