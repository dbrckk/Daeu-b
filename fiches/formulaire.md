## Calcul et algèbre
- Priorités : parenthèses, puissances, produits/quotients, sommes.
- $\frac ab+\frac cd=\frac{ad+bc}{bd}$ ($b,d\ne0$).
- $a^m a^n=a^{m+n}$ ; $a^{-n}=1/a^n$ ($a\ne0$).
- $(a+b)^2=a^2+2ab+b^2$ ; $(a-b)^2=a^2-2ab+b^2$ ; $a^2-b^2=(a-b)(a+b)$.
- $\Delta=b^2-4ac$ ; racines $x=(-b\pm\sqrt\Delta)/(2a)$ si $\Delta\ge0$, $a\ne0$.
- Sommet de $ax^2+bx+c$ : $\alpha=-b/(2a)$, $\beta=f(\alpha)$.

## Dérivation
- $(x^n)'=nx^{n-1}$ ; $(1/x)'=-1/x^2$ ; $(\sqrt x)'=1/(2\sqrt x)$ pour $x>0$.
- $(uv)'=u'v+uv'$ ; $(u/v)'=(u'v-uv')/v^2$.
- $(e^u)'=u'e^u$ ; $(\ln u)'=u'/u$ pour $u>0$ ; $(u^n)'=nu^{n-1}u'$.
- Tangente : $y=f'(a)(x-a)+f(a)$.
- $f'\ge0$ ⇒ non décroissante (sous les hypothèses usuelles) ; $f''\ge0$ ⇒ convexe.
- Asymptote oblique $y=ax+b$ si $f(x)-(ax+b)\to0$ à l'infini.

## Exp/ln
- $e^{a+b}=e^ae^b$ ; $e^{-a}=1/e^a$.
- $\ln(ab)=\ln a+\ln b$, $\ln(a/b)=\ln a-\ln b$ pour $a,b>0$.
- $\ln(e^x)=x$ ; $e^{\ln x}=x$ si $x>0$.
- $\ln x$ n'existe dans $\mathbb R$ que si $x>0$.

## Suites
- Arithmétique : $u_n=u_0+nr$, somme $S=(n+1)(u_0+u_n)/2$.
- Géométrique : $u_n=u_0q^n$, somme $S=u_0(1-q^{n+1})/(1-q)$ si $q\ne1$.
- Si $|q|<1$, $q^n\to0$.

## Statistiques et probabilités
- $\bar x=\sum n_i x_i/N$ ; $V=\sum n_i(x_i-\bar x)^2/N$ ; $\sigma=\sqrt V$.
- $P(\bar A)=1-P(A)$ ; $P(A\cup B)=P(A)+P(B)-P(A\cap B)$.
- $P(A\mid B)=P(A\cap B)/P(B)$ si $P(B)>0$.
- Loi $\mathcal B(n,p)$ (essais indépendants, même $p$) : $P(X=k)=\binom nk p^k(1-p)^{n-k}$, $E=np$, $V=np(1-p)$.

## Compléments locaux
- $\sin^2x+\cos^2x=1$, radians : $180^\circ=\pi$.
- $u\cdot v=ac+bd$ pour $u=(a;b)$, $v=(c;d)$.
- $\int_a^b f=F(b)-F(a)$ si $F'=f$.
- IPP : $\int_a^b uv'=[uv]_a^b-\int_a^b u'v$.
- $y'=ay$ ⇒ $y=Ce^{ax}$.
- Pour $z=a+ib$, $|z|=\sqrt{a^2+b^2}$, $\overline z=a-ib$, $i^2=-1$.
