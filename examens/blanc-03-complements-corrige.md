## Exercice 1 (7 points)
1. $\overrightarrow{AB}=(4-1;6-2)=\boxed{(3;4)}$ ; $AB=\sqrt{3^2+4^2}=\boxed5$ **(1)**.
2. Milieu $M((1+4)/2;(2+6)/2)=\boxed{(5/2;4)}$ **(1)**.
3. Pente $(6-2)/(4-1)=4/3$, droite $y=(4/3)x+b$ ; $2=4/3+b$, $b=2/3$ ; $\boxed{y=(4/3)x+2/3}$ **(1,5)**.
4. $(3;4)\cdot(4;-3)=12-12=0$ : vecteurs orthogonaux **(1)**.
5. $5\pi/6=\pi-\pi/6$, donc $\boxed{\sin(5\pi/6)=1/2,\;\cos(5\pi/6)=-\sqrt3/2}$ **(1)**.
6. Sur un tour : $\boxed{x=\pi/3\text{ ou }5\pi/3}$ **(1,5)**.

## Exercice 2 (7 points)
1. $F(x)=\boxed{x^3-x^2+x+C}$, dérivée bien $3x^2-2x+1$ **(1)**.
2. $[x^3-x^2+x]_0^2=8-4+2=\boxed6$ **(1,5)**.
3. $u=x$, $v'=e^x$, $u'=1$, $v=e^x$ ; $[xe^x]_0^1-\int_0^1e^x\,dx=e-(e-1)=\boxed1$ **(1,5)**.
4. $y'=-y+2$ s'écrit $y'+y=2$. Solution générale $y=2+Ce^{-x}$. $y(0)=2+C=0$ ⇒ $C=-2$. $\boxed{y=2-2e^{-x}}$. Vérification : $y'=2e^{-x}$ et $-y+2=-(2-2e^{-x})+2=2e^{-x}$ **(2)**.
5. Aire = $\int_0^1(1-x)\,dx+\int_1^2(x-1)\,dx=1/2+1/2=\boxed1$ unité d'aire **(1)**.

## Exercice 3 (6 points)
1. $\overline z=\boxed{1-i}$, $|z|=\boxed{\sqrt2}$, $\arg z=\boxed{\pi/4\ (\mathrm{mod}\ 2\pi)}$ **(1)**.
2. $(1+i)^2=1+2i+i^2=\boxed{2i}$ **(1)**.
3. $(1+i)/(1-i)=((1+i)^2)/2=2i/2=\boxed i$ **(1)**.
4. $\Delta=2^2-4\cdot1\cdot2=-4$ ; $\boxed{w=-1\pm i}$ **(1,5)**.
5. $(e^{i\pi/4})^4=e^{i\pi}=\boxed{-1+0i}$ **(1,5)**.
